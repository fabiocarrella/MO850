Measuring constructs with contextualized embeddings

Contextualized embeddings are dynamically generated based on the entire sentence or context in which a word appears.

The final representation of a word depends on the surrounding words (thanks to attention)

Contextualized embeddings are not designed to embed single words, which is needed for dictionary approaches (e.g., DDR).

Contextualized Construct Representation

Dictionaries are not the only curated resources to measure constructs.

Contextualized Construct Representation (or CCR)[1] leverages psychological questionnaires.

Straightforward pipeline:

  • extract embeddings per item in questionnaire

  • average the embeddings to have a CCR (aka centroid or reference vector)

  • embed texts

  • measure similarity (i.e., the extent) between texts and centroid

Since we are not using isolated words, we can take advantage of contextualized embeddings.

Psychometric Questionnaires

Questionnaires go through a thorough generation pipeline[2]:

  1. Identification of domain and item generation
    • Describe the construct of interest (and its dimensions)
    • Generate (many) items with deductive and/or inductive methods
    • Assessing content validity with expert and end users
  1. Scale development
    • (Pre) testing the items on the population
    • Reducing the items based on difficulty, discrimination, correlations
    • Extracting latent constructs with Factor Analysis
  1. Scale evaluation
    • Check if latent constructs are as hypothesized
    • Check reliability (internal consistency, test-retest)
    • Check validity (convergence, discrimination, correlation with existing scales)

From construct to questionnaire

The construct is not something real in itself, it is an attempt to indirectly measure real phenomena[3].

This causes the “jingle-jangle” jungle [4, 5]:

  • same construct label for different measures

  • different construct labels for same measure

Sources of questionnaires

Different sources offer questionnaires:

  • APA PsycTests (paid)

  • International Personality Item Pool

  • Psytoolkit

  • Open-source Psychometrics Project

  • Google Scholar

  • Ai2 Asta (or LLMs in general)

Anchored vectors

Word embeddings have analogical properties.

Relationships between words are preserved as vector arithmetic.

We can leverage this property to extract vectors between two embeddings.

These are called anchored vectors.

We can project embeddings onto anchored vectors to see how they position on a scale[6].

Properties of anchored vectors

Projecting on anchored vectors mitigates correlation problems between related reference vectors (e.g., happiness vs. sadness)

Anchored vectors also help reducing the effects of “questionnaire” style in CCR.

Warning

Additive analogies assume linear embeddings with consistent magnitudes.

Contextualized embeddings are nonlinear, so analogies often work poorly.

Correlational anchored vectors

We can use machine learning to create anchored vectors from data.

Using Partial Least Squares (PLS), we can extract a CAV that reflects the direction of maximum covariance with a dependent variable.

PLS is similar to PCA: both reduce dimensions, but PLS finds components that best predict the target variable, while PCA maximizes variance.

PLS does not need categorized data, it works with continuous variables too.
